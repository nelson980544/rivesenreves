encore une image provisoire « PHOTO À REMPLACER ». Déposez la photo dans
`src/static/assets/img/photos/` sous le nom indiqué (format `.webp` conseillé,
`.avif`, `.jpg` ou `.png` acceptés), puis relancez `python3 build.py`.
